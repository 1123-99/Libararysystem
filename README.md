# \# Librarysystem 图书管理系统

# \## 实验一：Book类设计与ISBN校验功能

# \### 项目简介

# 本项目使用C++实现图书Book类的封装，包含书名、作者、ISBN等图书属性，完成ISBN合法性校验。

# 校验规则：ISBN不允许包含英文字母，同时校验长度是否合法。

# 

\### 开发环境

# 开发工具：Visual Studio 2022

# 版本管理：Git，代码托管于GitHub

# 

# \### 文件说明

# \- book.h：Book类头文件

# \- book.cpp：Book类功能实现

# \- main.cpp：程序入口与测试逻辑
